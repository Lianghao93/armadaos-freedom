The vendor kernel snapshot stays fixed at `11a25bf89b65fff48112a91a0b25bc247e7736d8`.
This runtime patch **replaces** the vendor `0109`, it is not appended after it.

The candidate adds a 90 Hz mode (vendor `dtiming@5` as is) and a 165 Hz mode for
the baldur panel. The 165 Hz mode keeps the 120 Hz horizontal timing with the
shortest vertical total (Htotal 2244, Vtotal 3120). The recorded mode clock is
1155211 kHz, so the actual rate is about 164.99997 Hz
(`clock * 1000 / (2244 * 3120)`); the previous 164 Hz clock is not reused.
