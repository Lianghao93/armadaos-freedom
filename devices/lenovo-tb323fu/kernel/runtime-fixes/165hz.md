# 165 Hz panel mode

The vendor kernel snapshot remains fixed at `11a25bf89b65fff48112a91a0b25bc247e7736d8`.
This patch **replaces** the vendor `0109`; do not append it after that patch.

- Vendor original: `../tb323fu-linux-11a25bf8/tb323fu-linux-11a25bf89b65fff48112a91a0b25bc247e7736d8/kernel/patches/0109-drm-panel-nt36523-baldur-add-90-Hz-and-164-Hz-modes.patch`.
- Replacement: [0109-drm-panel-nt36523-baldur-add-90-Hz-and-165-Hz-modes.patch](0109-drm-panel-nt36523-baldur-add-90-Hz-and-165-Hz-modes.patch).

The replacement adds the vendor `dtiming@5` 90 Hz mode and a 165 Hz mode for the baldur panel. The latter retains the 120 Hz horizontal timing and uses Htotal 2244, Vtotal 3120, and a 1155211 kHz pixel clock. The computed refresh is about 164.99997 Hz; it does not reuse the old 164 Hz clock.

Physical 90 Hz corruption remains unresolved. The Gamescope EDID clamp is a separate metadata correction and does not fix physical panel timing. Patch-header wording reflects its original development state; build and deployment reports are maintained outside this repository.
