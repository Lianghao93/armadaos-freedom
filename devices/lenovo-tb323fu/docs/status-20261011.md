- 双 USB 路由恢复：长边充电时短边手柄拔插恢复已由用户确认；其他插拔顺序、休眠仍待测。

## 仍未完成

1. 90 Hz 偶发物理花屏；165→90 是临时恢复手段。
2. Steam 主界面低帧与动态帧时间不均，以及此前崩溃 / 重启原因。
3. SGSR 与高刷的组合问题按用户决定交由上游，本次不增加 SGSR 实验补丁。
4. 复杂场景固定三倍补帧仍不稳定，小黄鸭实验核心和 WSI 改动继续在独立仓库整理，本次不复制其核心、安装包或诊断开关。
5. Android 固件沿用的 80% 充电上限尚无 Linux 调节入口。
6. 当前机身根分区仍是早期 flat ext4，未达到所要求的 Btrfs / OSTree 布局；不会把该偏差当作正式安装方案。
7. 内核 / 引导完整可复现打包、设备 overlay 自动安装及 Armada 系统更新链尚未接通。仓库源码同步不等于可发布镜像或系统内 OTA 已完成。
