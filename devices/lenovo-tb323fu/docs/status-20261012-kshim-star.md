# 2026-10-12：kShimC STAR 菜单与已验证内核恢复

本轮将已部署的 STAR 菜单源码、构建配方及既有证据同步到私有维护仓库。用户已确认整体菜单测试无问题；后台确认新引导镜像进入机身 Linux `7.3.0-rc4-tb323fu-t42 #5`，Gamescope、Steam 与 Steam WebHelper 正常运行。这里不将整体菜单反馈扩展为所有高级操作或语言切换均已逐项验收。

## 实现范围

- 为 TB323FU 选择独立 `STAR_CHART` 主题：深蓝底、米白文楷、浅金选中项及静态羽毛、星点、轨道线稿。实际逻辑画布为 **3040×1904**，保留已验收的横屏方向；1920×1080 只是兼容预览，不是该设备的原生比例。
- 左侧列出原厂 Android、机身 ArmadaOS、TF 卡 ArmadaOS、高级启动模式、语言、重启和关机；右侧随当前项更新说明，下方保留按键提示和操作按钮。
- 高级页包含 Linux 诊断、Recovery、Fastboot、9008 和返回。语言页包含简体中文、English 和返回。音量键选择、电源键确认，未启用触摸。
- 切换语言后刷新标题、菜单项、说明、按钮、倒计时、按键提示和署名；取消当前倒计时并返回主菜单的语言项。语言是本次开机内的设置，重启默认中文，不写持久化分区。
- 中文署名为「适配维护：B站『单翼』｜免费使用，谨防收费诈骗。」；英文为 `Adapted by Danyi on Bilibili · Free to use. Beware of paid scams.`

这是固件中直接绘制的界面，不是把概念图贴到 framebuffer。文案保持可切换；静态线稿没有额外的粒子动画。此前的主题、字体、高级启动实现、横屏修正及启动 DT 解析修复仍保留在完整源码快照中。

## 字体和固件内存

WenKai 菜单资产为 **86,077 字节**，包含 686 个字形；本轮必需文案的 233 个非空白字符均有覆盖。保留字体来源 JSON 和 OFL 授权文件。该资产不是完整中文字库，后续新增菜单文案须按 [构建说明](../boot/star-chart-build/README.md)重新检查字形覆盖。

完整字体候选曾超过固定 4 MiB runtime 边界，最终使用菜单子集，未扩大固件内存。最终 runtime 已用 3,370,624 字节，剩余 823,680 字节；64 KiB 堆、256 KiB 栈和 LVGL 的 512 KiB 堆预算保持不变。

512 KiB 菜单验证还发现 STAR 确认缩放需要约 252,840 字节临时图层，分配失败后反复重试。最终仅取消 STAR 的确认缩放动画，保留确认操作；未扩大堆或改动其他主题的动画行为。修正后的固件堆路径通过实际菜单测试。

## 实机结果

本轮经用户批准写入 96 MiB `boot_a`，完整回读与候选一致后重启。按用户要求恢复到已验证的 #5 Linux payload，并配套恢复 GPU 旋转设置；后台确认机身 root 挂载可读写，Gamescope 使用原有横屏及合成旋转参数，Steam 已运行。

| 对象 | SHA-256 |
|---|---|
| 本轮 boot 镜像 | `3e9ca47df76c123a42f2a72b6769750971fb37639fa8e14ed78bac9f526310d1` |
| 本轮 kShimC runtime | `8f49609199586e27fccf07e5feff966e95e733ba05987b0c35f607153092c13e` |
| 保留的 #5 Linux payload | `bfcc03543585aa9f7015917eebcb20fade8c1ef849080e459f653f8bd1c3a38d` |

引导包的八个条目只更新 shim，其余七个条目的内容、位置和标记与构建基底一致。菜单默认仍为机身 Linux、8 秒倒计时；用户操作可取消自动选择。实体测试反馈为整体菜单无问题，**Recovery、Fastboot、9008、Linux 诊断及语言切换没有本轮逐项单独确认记录**。

## 启动计时的正确解释

本轮日志显示：

- 从 kShimC C 入口到菜单首帧为 **58.077 秒**。
- 从菜单首帧到选择返回为 **605.057 秒**，包含用户在菜单中等待及操作的时间，不能计入程序加载耗时。

这说明菜单前仍有需要继续定位的延迟；不能用约十分钟的菜单停留时间宣称启动更慢，也不能据此宣称此前五分钟问题已经全部解决。C 入口之前及选择之后的时间尚未由这两个指标完整覆盖。

## 仍未完成

- 高级启动项及语言切换需要最小范围的单独实机验收；语言持久化未实现。
- 本次菜单更新不解决 Steam 主界面高刷、90 Hz 偶发物理花屏或完整硬件旋转问题。设备 profile 维持 `ARMADA_GAMESCOPE_USE_ROTATION_SHADER=1`，没有混入新的旋转试验。
- SGSR 和小黄鸭核心没有随本轮修改，保留用户的 60% / 80% 性能设置。
- Y700 的正式镜像构建、内核移植至 Armada 维护链及系统内 OTA 尚未接通。当前源码同步不是镜像发行验收。

旧 quiet GPU 调整、打包器补丁和此前记录继续保留。库内只保留源码、构建配方、必要静态预览和去除设备连接信息的验证证据，不上传镜像、现场备份或连接脚本。
